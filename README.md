# ⚔️ Solo Leveling App

> **Прокачуй себе як персонажа RPG.** Щоденні квести, система рівнів, досягнення та статистика — усе в одному мобільному додатку, натхненному всесвітом Solo Leveling.

---

## 📖 Про проект

**Solo Leveling App** — Android-додаток для особистого розвитку, побудований на метафорі рольових ігор. Замість нудних списків задач тут є система, яка нагадує вам про квести, нараховує досвід за їх виконання та карає за бездіяльність — так само, як у справжній грі.

Ідея: кожен день — це данж, а ваші щоденні звички — квести. Виконав усі? Отримуєш XP та ростеш у рівні. Не виконав? Наступного дня цілі зростають на 50%.

---

## 🎯 Основні можливості

### ⚡ Система квестів
- Щоденні квести з власними назвами, нагородами XP та цілями
- Чотири категорії: `physical` (фізична), `mental` (ментальна), `coding` (програмування), `languages` (мови)
- **Звичайний тап** — миттєве позначення виконаного / скасування
- **Затримання 1.5с** — відкриває діалог точного введення прогресу (наприклад, 20/30 сторінок або 40/30)
- Відображення прогресу `виконано / ціль` для кожного квесту

### 📈 Система досвіду та рівнів
| Ситуація | Розрахунок |
|---|---|
| Виконання квесту | `expReward` XP |
| Виконання квесту-штрафу | `expReward × 1.5` XP |
| Перевиконання | `(overshot × expReward/target) × multiplier` |
| Зниження прогресу нижче цілі | XP списується у зворотньому порядку |

**Множник за перевиконання залежить від рівня:**
```
multiplier = 1.0 + (level / 10) × 0.01

Рівень 0–9   → ×1.00  (без бонусу)
Рівень 20    → ×1.02
Рівень 100   → ×1.10
Рівень 200   → ×1.20
```

**Поріг левелапу:** `xpToNextLevel = 100 + 10 × currentLevel`

### 🔁 Щоденне скидання
- При запуску додатку автоматично перевіряється, чи настав новий день
- **Усі квести виконані** → прогрес скидається, цілі повертаються до початкових, нараховується "ідеальний день" до досягнення
- **Є невиконані квести** → ціль кожного невиконаного квесту зростає на 50% (`target × 1.5`), квест отримує статус `isPenalty = true`
- **Перший запуск** → ініціалізація без штрафу

### 🏆 Досягнення
П'ять досягнень з рангами **E → D → C → B → A → S**:

| Досягнення | ID | Відстежує |
|---|---|---|
| Архітектор Системи | `system_architect` | Дні кодингу |
| Бібліотека Монарха | `monarch_library` | Сторінки прочитано |
| Лінгвістичний Поліглот | `polyglot` | Дні практики мов |
| Шлях до Олімпу | `road_to_olympus` | Виконані підходи |
| Гравці в реальне життя | `players_irl` | Ідеальні дні |

Пороги для кожного досягнення: `10 → 50 → 100 → 500 → 1000 → 10000`

### 📊 Статистика та графіки
- Відображення статистики фізичної активності та інших показників
- Стовпчасті графіки з інтерактивними підказками (тап по стовпчику → точне значення)
- Мітки осей: дати знизу, значення збоку
- Відображення кількох метрик (кроки, активність тощо)

### 🔔 Сповіщення
Три типи сповіщень за часом:
- **07:00–12:00** → нагадування про нові квести
- **17:00–21:00** (за умови невиконаних квестів) → попередження про можливий штраф
- **Наступний ранок** (за умови нарахованого штрафу) → повідомлення про отриманий штраф

### 👤 Профіль гравця
- Нікнейм, дата народження, рівень, поточний XP, прогрес до наступного рівня
- Відображення рангу та аватара в стилі Solo Leveling

## 🏗️ Архітектура

Проект побудований за принципами **Clean Architecture** з чіткими шарами:

```
app/
└── src/main/java/ua/zxcode/sololevelingapp/
    ├── core/
    │   ├── health/          # Health Connect інтеграція
    │   ├── navigation/      # Навігаційний граф (Compose Navigation)
    │   └── work/            # WorkManager задачі та менеджер скидання
    ├── data/
    │   ├── local/
    │   │   ├── dao/         # Room DAO інтерфейси
    │   │   ├── db/          # AppDatabase, міграції
    │   │   └── entity/      # Room Entity класи
    │   └── repository/      # Реалізації репозиторіїв
    ├── di/                  # Hilt модулі ін'єкції залежностей
    ├── presentation/
    │   ├── achievements/    # Екран досягнень та утиліти рангів
    │   ├── components/      # Спільні UI компоненти
    │   ├── home/            # Головний екран (квести, профіль)
    │   └── stats/           # Екран статистики з графіками
    └── ui/                  # Тема, кольори, типографіка
```

### Шари та їх відповідальність

| Шар | Відповідальність |
|---|---|
| `entity/` | Дата-класи для Room (таблиці БД) |
| `dao/` | SQL запити через Room анотації |
| `repository/` | Абстракція доступу до даних |
| `work/` | Фонові задачі (WorkManager) та `DailyResetManager` |
| `presentation/` | Compose UI, бізнес-логіка рівня екрану |

## 🗄️ База даних

**Room** v2.8.4 · SQLite · Поточна версія схеми: **5**

### Таблиці

#### `user`
| Поле | Тип | Опис |
|---|---|---|
| `id` | Int (PK) | Завжди `1` (один профіль) |
| `nickname` | String | Нікнейм гравця |
| `currentLevel` | Int | Поточний рівень |
| `currentXp` | Int | Поточний досвід |
| `xpToNextLevel` | Int | XP до наступного рівня |
| `gender` | String | Стать |
| `birthDate` | String | Дата народження |
| `isSoundEnabled` | Boolean | Звук вкл/викл |
| `lastResetDate` | String | Дата останнього добового скидання (`yyyy-MM-dd`) |
| `hadPenaltyYesterday` | Boolean | Чи нараховувався штраф вчора |

#### `quests`
| Поле | Тип | Опис |
|---|---|---|
| `id` | Long (PK, auto) | Унікальний ідентифікатор |
| `title` | String | Назва квесту |
| `expReward` | Int | Нагорода XP за виконання |
| `isCompleted` | Boolean | Статус виконання |
| `category` | String | `physical` / `mental` / `coding` / `languages` |
| `progress` | Int | Поточний прогрес |
| `target` | Int | Цільове значення (може зростати при штрафі) |
| `isPenalty` | Boolean | Чи є цей квест штрафним |
| `originalTarget` | Int | Первинна ціль (для повернення після виконання) |

#### `achievements`
| Поле | Тип | Опис |
|---|---|---|
| `id` | String (PK) | Стабільний ідентифікатор |
| `title` | String | Назва |
| `iconResId` | Int | ID ресурсу іконки |
| `currentRank` | Int | `-1`=не розпочато, `0`=E, `1`=D, `2`=C, `3`=B, `4`=A, `5`=S |
| `progress` | Long | Накопичений прогрес |
| `isCompleted` | Boolean | `true` при досягненні рангу S |

#### `stats` / `stat_records`
Таблиці для зберігання метрик (кроки, активність) та їхньої денної/тижневої історії. Зв'язок `CASCADE DELETE`: при видаленні стату видаляються всі його записи.

### Міграції
| Версія | Зміни |
|---|---|
| 4 → 5 | Додано `lastResetDate TEXT` та `hadPenaltyYesterday INTEGER` до таблиці `user` |

## 🚀 Встановлення та запуск

### Вимоги
- Android Studio Meerkat або новіше
- JDK 11+
- Android SDK 36
- Пристрій або емулятор з Android 16+

### Кроки

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/your-username/SoloLevelingApp.git
   cd SoloLevelingApp
   ```

2. **Відкрийте у Android Studio:**
   `File → Open → вибрати папку SoloLevelingApp`

3. **Синхронізуйте Gradle:**
   Android Studio запропонує синхронізацію автоматично.

4. **Запустіть:**
   - Підключіть пристрій або запустіть емулятор
   - Натисніть `Run ▶` або виконайте:
   ```bash
   ./gradlew assembleDebug
   ```

### Збірка APK
```bash
./gradlew assembleDebug
# APK буде у: app/build/outputs/apk/debug/app-debug.apk
```

## ⚙️ Логіка добового скидання

```
При запуску додатку:
  ├─ lastResetDate == today?  →  нічого не робити
  ├─ lastResetDate == ""?     →  перший запуск, ініціалізувати без штрафу
  └─ інакше:
       ├─ всі квести виконані?
       │    ✅ → скинути прогрес, відновити originalTarget, +1 до "ідеальних днів"
       └─ є невиконані?
            ⚠️ → target × 1.5, isPenalty = true, hadPenaltyYesterday = true
```
